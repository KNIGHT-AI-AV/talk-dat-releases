# Talk DAT! Releases

This repository is the official binary distribution channel for
[Talk DAT!](https://www.talkdat.app/), Knight AI+AV's dictation app for Windows and
Mac. It contains compiled installers, portable builds, SHA256 checksums, and
machine-readable release receipts. This repository holds no source code, API keys,
user configuration, transcripts, recordings, dictionaries, model weights, or private
customer data.

This repository is public because the in-app updater checks it for new releases.
That is its only job. It used to also host a second full copy of the customer
website, which is exactly what let the real website fall out of date: only this
copy was published automatically. The website now has a single home at
[www.talkdat.app](https://www.talkdat.app/), and the customer-site
workflow replaces the GitHub Pages copy here with a redirect to it once that
deploy runs.

## Download

Start at the [official Talk DAT! product page](https://www.talkdat.app/),
or use this repository's [Releases page](https://github.com/KNIGHT-AI-AV/talk-dat-releases/releases)
directly. The product page and the in-app updater both resolve releases from this
channel and verify the selected installer against its receipt and SHA256 digest.

## Windows updates

New Windows versions of Talk DAT! are released only in the Microsoft Store: https://apps.microsoft.com/detail/9NF64GDNBPF5. Version 0.4.178 is the last direct Windows installer here, and installs from it do not update to newer versions. To keep getting updates, install Talk DAT! from the Microsoft Store. Mac releases continue here.
